# 연기 입시 공고 데이터

연극영화과 실기 전형 정보를 손으로 확인해 채운 파일이다. `notices.json` 하나가 전부이고,
`GET /v2/admissions`가 이 파일을 읽어 내보낸다.

## 왜 크롤러가 아닌가

대학 입학처와 대입정보포털(adiga)이 **자동 수집을 막아 두었다.**

```
admission.cau.ac.kr    User-agent: *  Disallow: /
ipsi.dankook.ac.kr     User-agent: *  Disallow: /
adiga.kr               Disallow: /ucp/prc/uni/admssUnivView.do  (대학별 입학전형)
                       Disallow: /ucp/uvt/uni/univView.do
iphak.hanyang.ac.kr    robots.txt 없음 (명시적 허용도 없음)
```

공공데이터포털의 대학 API(커리어넷 대학학과정보, 대학알리미)는 학과·정원 정보라
**전형 일정과 실기 과제가 없다.**

그리고 입시 정보는 틀리면 사용자에게 실제 피해가 간다. 서울권 연극영화과는 스무 곳
남짓이라, 시즌마다 사람이 원문을 확인해 채우는 편이 자동 파싱보다 정확하고 싸다.

## 가장 중요한 규칙

**확인하지 않은 값은 채우지 않는다.** 비워 두거나 `null`로 남긴다. 그럴듯한 날짜를 지어
넣는 것이 이 데이터에서 제일 위험한 실수다.

- 모든 항목에 `verified_at`(사람이 원문을 확인한 날짜)을 남긴다.
- 화면은 항상 원문 링크와 안내 문구(`disclaimer`)를 함께 보여준다.
- 날짜는 `YYYY-MM-DD`. 기간은 `apply_start`/`apply_end`로 나눈다.
- 미확정이면 `null` + `note`에 사정을 적는다.

### 값의 출처는 대학 공식 요강뿐

진학사·메가스터디 같은 사설 업체 자료는 **어느 대학에 연기 모집단위가 있는지 찾는
인덱스로만** 쓴다. 경쟁률·등급컷·일정 같은 숫자를 그쪽에서 옮겨 오지 않는다. 상업
데이터라 출처를 밝힐 수 없고, 2차 가공을 거치며 틀어지기 때문이다.

### 서술형이 정본, 구조화 필드는 보조

`stages` · `practical_items` · `weights`는 필터와 비교를 위해 원문을 쪼갠 것이다.
대학마다 실기 구성이 제각각이라 여기에 다 담기지 않는다. **원문 서술(`practical_task`,
`dress_code`)은 항상 그대로 남기고**, 구조화 필드는 확실한 것만 채운다.

`weights`는 특히 조심한다. 모집요강 PDF의 표를 텍스트로 뽑으면 행·열이 뒤엉켜
오독하기 쉬운데, 이 값이 틀리면 지원 전략을 통째로 그르친다. **숫자가 문장이나 표에
또렷하게 적혀 있을 때만 채우고, 조금이라도 애매하면 전부 `null`로 두고 원문 표기를
`weights_note`에 그대로 옮긴다.**

### 부팅 때 걸러지는 것

`admissions.py`의 `load_admissions()`가 파일을 읽으며 검사한다. 걸리면 서버가 뜨지
않으므로 배포 전에 드러난다.

- `notices[].university_id`가 `universities[].id`에 없음
- `universities[].id` · `notices[].id` 중복
- `discipline`이 `acting|musical`이 아님
- `universities[].type`이 `univ|college`가 아님
- `practical_items[].category` · `stages[].evaluates[]`가 정해진 목록 밖
- `stages[].order` 중복, `practical_items[].stage`가 없는 단계를 가리킴

허용되는 실기 종목(`category`):
`free_acting`(자유연기) · `assigned_acting`(지정연기) · `improv`(즉흥) · `song`(노래) ·
`dance`(무용) · `movement`(신체표현) · `special`(특기) · `interview`(면접) ·
`essay`(작문) · `audition_etc`(그 외)

## 구조

```jsonc
{
  "updated_at": "2026-07-31",
  "disclaimer": "최종 확인은 반드시 각 대학 입학처 공고로 해주세요.",
  "universities": [                      // 공식 입학처 링크. 주소가 실제로 200을 주는지 확인함
    { "id": "cau", "name": "중앙대학교",
      "admission_url": "https://admission.cau.ac.kr", "verified_at": "2026-07-31" }
  ],
  "notices": [                           // 전형별 상세. 원문을 읽고 채운다
    { "id": "cau-2027-susi-practical",
      "university_id": "cau",            // universities[].id 를 가리킨다
      "department": "공연영상창작학부 연극전공",
      "discipline": "acting",            // acting | musical
      "admission_year": 2027,            // 2027학년도 = 2026년에 치르는 입시
      "track": "수시",                    // 수시 | 정시
      "screening": "실기형",
      "apply_start": null, "apply_end": null,
      "practical_date": null,            // 여러 날이면 첫날
      "practical_date_end": null,        // 마지막 날 (하루면 생략)
      "announce_date": null,             // 합격발표일
      "practical_task": null,            // 자유연기·지정연기 등 요약 — 이게 정본
      "weights": { "practical": 70, "transcript": 30 },   // 확실할 때만
      "weights_note": null,              // 애매하면 원문 표기를 여기에
      "stages": [
        { "order": 1, "name": "1차 실기", "date": "2026-10-10",
          "evaluates": ["free_acting"], "multiple": "5배수", "weight": 0 }
      ],
      "practical_items": [
        { "category": "free_acting", "label": "자유연기",
          "required": true, "time_limit_sec": 120, "count": 1, "stage": 1 }
      ],
      "source_url": "https://...",       // 그 전형이 실린 원문 페이지
      "verified_at": null,
      "note": "2027학년도 모집요강 확인 필요" }
  ]
}
```

`universities[]`에는 `campus`("서울"·"ERICA"처럼 캠퍼스별로 전형이 갈릴 때)와
`type`(`univ` 4년제 / `college` 전문대)도 둔다. 둘 다 화면 필터로 쓰인다.

### 2027 정시요강은 대부분 아직 없다

2026-08-04 기준으로 정시 모집요강을 낸 대학이 거의 없다. 정시 공고는 전형시행계획을
근거로 채우고 **확정되지 않은 원서접수일·실기일·전형료는 `null`로 뒀다.** 시행계획조차
없으면 공고를 만들지 않았다.

성신여대 정시가 가장 심한 경우다. 확인된 사실이 "정시 7명"뿐이고 **실기를 보는지조차
모른다.** 그래도 남겼다 — 없는 것과 모르는 것은 다르고, 무엇을 모르는지 `note`에 적었다.

## 전년도 입시결과

**실기 성적 커트라인은 어느 대학도 공개하지 않는다.** `results`에 담기는 등급은 전부
최종등록자의 *학생부 교과* 성적이다. 화면에서도 이 점을 밝힌다.

| 대학 | 공개 여부 | 근거 |
|---|---|---|
| 동국대 | 연극학부 실기형·특기형, 2개년 | 입시결과 PDF — 경쟁률·학생부·충원율 |
| 명지대 | 뮤지컬공연전공 보컬·댄스 | 모집요강 PDF 87쪽에 직접 실려 있음 |
| 성균관대 | 전형 총계만 | 실기/실적 전형을 학과별로 쪼개지 않는다 |
| 건국대 | **없음** | 2026 입시결과에 실기/실적 전형 자체가 없다(학생부·논술만) |
| 세종대 | 미확인 | 자료실 게시판이 JS 렌더링 |
| 한예종·중앙대·단국대·서울예대 | 미확인 | — |

사설 입시업체(진학사·메가스터디 등)의 예측 커트라인은 쓰지 않는다. 상업 데이터이고
출처를 밝힐 수 없다.

## robots.txt로 막힌 곳

같은 기준을 끝까지 적용했다. **입학처가 자동 수집을 막아 둔 곳은 긁지 않는다.**
우회하지 않고, 다른 도메인으로 돌아가지도 않는다.

현재 **17곳**이 여기 해당해 링크만 남아 있다: 중앙대 · 단국대 · 청강문화산업대 ·
국민대 · 서경대 · 백석예술대 · 안양대 · 동아방송예대 · 계명대 · 호서대 · 전주대 ·
백석대 · 청운대 · 상명대 · 순천향대 · 동신대 · 경일대 · 대구과학대 · 홍익대 ·
호원대 · 숭의여대 · 성결대 · 수원대 · 인천대 · 부산예술대.

차단 방식이 몇 갈래다.

| 유형 | 예 |
|---|---|
| 전면 `Disallow: /` | 중앙대, 단국대, 성결대, 호원대, 인천대 |
| **ClaudeBot을 이름으로 지정** | 숭의여대, 홍익대, 안양대, 전주대 |
| 요강 경로만 차단 | 청강문화산업대(`/data/`), 부산예술대(`/page/sub03`), 수원대(안내는 Allow인데 요강 PDF가 있는 `/upload_data/guide/`는 Disallow) |
| 검색엔진 봇만 예외 | 국민대, 호서대, 계명대 |

수원대가 까다로운 경우다. 입학 안내 페이지는 `Allow`라 읽히는데 정작 모집요강 PDF는
허용 경로 밖이라, 실질적으로는 요강을 못 받는다.

**전부 사람이 브라우저로 열어 보는 것은 막혀 있지 않다.** 원문 PDF를 받아
`admissions/`에 넣어 주면 파싱해서 채울 수 있다.

## 참고 영상 (`universities[].resources`)

**링크만 담는다. 영상 설명이나 후기 본문은 옮기지 않는다** - 남의 저작물이다.

`source_type`은 반드시 붙인다. 지금 22건 중 **12건이 입시학원 홍보 영상**이고, 제목만
보면 대학 공식 자료처럼 읽히는 것도 있다(예: "[중앙대] 중앙대학교 연극학과 신입생의
솔직한 인터뷰" - 실제로는 RAON ACTORS 채널). 구분 없이 늘어놓으면 입시생이 광고를
정보로 읽는다.

| 값 | 뜻 |
|---|---|
| `official` | 대학·학교 방송국 공식 채널 |
| `school` | 고등학교 채널 |
| `academy` | 입시학원 |
| `personal` | 개인 |

**"합격생"은 본인 주장이고 우리가 검증한 것이 아니다.** 화면에도 그렇게 적는다.
링크는 YouTube oEmbed로 살아 있는지, 채널명이 무엇인지 확인한 뒤 넣는다.

## 갱신

시즌 시작 전(보통 4~5월 전형계획, 8~9월 모집요강)에 원문을 다시 읽고 갱신한다.
`verified_at`이 오래된 항목은 화면에서 "확인 필요"로 표시할 수 있다.
