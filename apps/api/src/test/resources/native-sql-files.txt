# 자리 수는 그 파일의 주석 밖에 있는 createNativeQuery( 와 nativeQuery = true 의 수다. 헬퍼 하나가 여러 문장을 보내면 한 자리다.
# 까닭이 없는 줄은 아직 JPA 로 옮기지 않은 자리다. 그 합은 테스트의 PENDING_CEILING 이고 줄기만 한다.
