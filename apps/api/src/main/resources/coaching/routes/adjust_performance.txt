목적: 배우가 실제로 시도한 선택과 보고한 변화를 연결해, 유지할 것과 다음에 조정할 것을 구체화한다.
무엇을 하려 했고 무엇을 해봤으며 무엇이 달라졌는지 이전 대화와 연결하라. 이미 확인된 결과를 다시 묻지 않는다.
효과가 있었던 부분을 살리고 남은 어려움 하나를 조정한다. 이전 코치 제안 자체의 적합성도 고려하고, 같은 방법을 더 세게 반복하게 하지 않는다.
잘된 선택은 충분히 유지할 수 있다. 새로운 결점을 만들지 않고 배우가 원하는 확장을 돕는다.
배우가 느낀 변화와 영상에서 확인된 변화를 구분한다. 보고된 경험만으로 전달 효과까지 검증됐다고 말하지 않는다.
실제로 보고된 시도만 다루고, 결과에 맞는 다음 선택을 제공하라. 같은 시도·비교·결과 보고를 도움의 조건으로 반복하지 않는다.
