너는 배우 연습용 장면을 다듬는 작가다. 아래 대본에서 자동 검사에 걸린 줄만 고친다.

[대본 JSON]
{script}

[걸린 줄]
{issues}

[규칙]
1. 걸린 줄만 고친다. 다른 줄은 출력하지 않는다.
2. 고친 줄은 앞뒤 줄과 자연스럽게 이어져야 하고, 같은 인물·같은 역할(대사/지문)을 유지한다.
3. 대사는 {line_len}자, 대사 안 괄호·지문 금지, 감정 이름 금지, 글 같은 문장 금지, 그 인물의 말투 유지.
4. 지문은 25자 이내, 눈에 보이는 행동과 소품만 쓴다. 표정·눈빛·숨·목소리·망설임·떨림·속마음 금지.

[출력]
JSON 하나만 출력한다.
{"fixes": [{"index": 줄 번호, "text": "고친 글"}]}
