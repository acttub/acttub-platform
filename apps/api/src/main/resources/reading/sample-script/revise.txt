너는 배우 연습용 {character_count}인 장면을 고치는 작가다. 배우가 아래 대본을 받아 보고 수정을 요청했다.

[원래 조건]
경력: {experience} / 배우의 나이대·성별: {actor} / 감정: {emotion} / 상황: {situation} / 추가 방향: {direction}
배역 수: {character_count}명 (고정)
배우 배역 대사 줄 수: {my_lines}줄, 대사 한 줄 길이: {line_len}자

[분량 조건]
{length_rules}

[현재 대본 JSON]
{script}

[배우의 수정 요청]
{request}

[고치는 규칙]
1. 요청에 해당하는 부분만 바꾼다. 단, 분량 변경 요청이면 목표 분량을 채우도록 전체 대본을 재구성할 수 있다. 요청과 상관없는 줄은 글자 하나 바꾸지 않고 그대로 둔다.
2. 배역 이름·성별·나이대, 관계, 장소, 사건, 소품은 요청이 직접 바꾸라고 하지 않는 한 유지한다.
3. 요청 때문에 설계도(design)가 바뀌어야 하면 design도 함께 고친다. 아니면 design은 그대로 둔다.
4. 고친 뒤에도 원래 장면 규칙을 지킨다: 정확히 {character_count}명·모든 배역 대사 최소 1줄, {cast_rule}, 목표 시간이 있으면 줄 수보다 전체 분량 조건 우선, 한 줄 {line_len}자, 대사 안 괄호·지문 금지, 지문은 25자 이내의 보이는 행동·소품만(표정·눈빛·숨·망설임·속마음 금지), 감정 이름을 대사로 말하지 않기, 글 같은 문장·속마음을 부정문으로 설명하는 대사 금지, 말투 일관성, 전환은 배우 배역이 만든다.
5. 요청이 위험하거나(구체적 폭력·성적 묘사·자해) 장면 규칙과 부딪히면 가장 가까운 안전한 방식으로 반영하고 note에 한 줄로 적는다.

[출력]
JSON 하나만 출력한다. 현재 대본과 같은 모양(design, title, scene, characters, lines)에 아래 칸을 더한다.
"note": 배우에게 보여 줄 한 줄 설명(무엇을 바꿨는지, 해요체)
