# 대본 리딩 고품질 목소리 동의 (필수)

시행일: 이 판이 발행된 날 (앱의 가입 동의 화면과 설정의 동의 목록에 표시됩니다)

이 동의는 **필수**입니다. Acttub는 대본 리딩의 상대역 목소리를 기본 기능으로 제공하므로, 서비스를 이용하려면 이 동의가 필요합니다. 고품질 목소리를 실제로 켤지는 리딩 화면에서 따로 고를 수 있습니다.

## 1. 무엇에 동의하나요
대본 리딩에서 「고품질 목소리」를 켜면, 상대역 대사를 더 자연스러운 목소리로 읽어 주기 위해 **상대 대사 문장**을 회사 서버를 거쳐 Google의 음성 합성 서비스(Gemini)로 보냅니다. 켜지 않으면 대사는 기기 밖으로 나가지 않고 기기 안에서 음성으로 바뀝니다.

## 2. 보내는 항목
- 상대역 대사 문장 한 줄과 고른 목소리 종류

대본 제목, 배역 이름, 이용자의 이름·이메일 등 이용자를 알아볼 수 있는 정보는 보내지 않습니다. 이용자가 말한 내 대사와 녹음도 보내지 않습니다.

## 3. 처리 목적
상대역 대사를 음성으로 만들어 리딩 중에 들려주는 것. 이 밖의 목적으로 쓰지 않습니다.

## 4. 수탁자와 국외 이전
- 수탁자: Google (Gemini)
- 이전 국가: Google이 운영하는 국외 서버
- 이전 시점·방법: 고품질 목소리가 켜진 리딩에서 상대 대사를 읽을 때마다 암호화된 네트워크로 전송
- 자세한 위탁·국외 이전 현황은 개인정보 처리방침에서 안내합니다.

## 5. 보관 기간
- 만들어진 음성은 같은 문장을 다시 만들지 않도록 회사 저장소에 보관합니다. 이 음성은 문장과 목소리 종류로만 찾으며 **어느 이용자가 요청했는지와 연결하지 않습니다.**
- 이용자별로는 하루 이용 줄 수만 남기고, 탈퇴하면 지웁니다.

## 6. 동의를 바꾸는 방법
필수 동의이므로 회원인 동안에는 거둘 수 없고, 거두려면 탈퇴합니다. 다만 리딩 화면에서 고품질 목소리를 끄면 그때부터 대사를 보내지 않고 기기 안의 목소리로 읽습니다.

## 7. 동의를 거부할 권리
이용자는 이 동의를 거부할 수 있습니다. 다만 필수 동의이므로 거부하면 서비스에 가입하거나 계속 이용할 수 없습니다.
