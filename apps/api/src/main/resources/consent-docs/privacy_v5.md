# 개인정보 수집·이용 동의

시행일: 이 판이 발행된 날 (앱의 동의 화면과 설정의 동의 목록에 표시됩니다)

Acttub(이하 "회사")은 서비스를 제공하기 위해 아래와 같이 개인정보를 수집·이용합니다. 이 문서는 **동의를 받는 문서**입니다. 위탁·국외 이전·이용자의 권리 등 처리 전반은 동의 대상이 아닌 고지 문서인 **개인정보 처리방침**에서 따로 안내합니다.

## 1. 계정에 필요한 항목
- 소셜 로그인 식별자(Google·Apple·카카오·네이버가 제공하는 계정 식별값)
- 이메일 주소 — 로그인 제공자가 **검증했다고 알려 준 주소만** 저장합니다. 이메일 제공에 동의하지 않았거나 검증되지 않은 주소는 저장하지 않습니다.

이용 목적: 본인 확인과 로그인, 다른 로그인 방식으로 들어와도 같은 계정으로 이어 주기.

## 2. 프로필 필수 항목
가입할 때 아래 여섯 항목을 한 번 입력받습니다. 모두 AI 코치가 첫 연습부터 이용자에게 맞춰 말하기 위해 쓰이며, 이용자는 설정에서 언제든 고칠 수 있습니다.

| 항목 | 코칭에 쓰는 이유 |
| --- | --- |
| 이름 | 코치가 이용자를 부르는 호칭이며, 챌린지 참여작과 댓글에 작성자 이름으로 표시됩니다 |
| 성별 | 배역과 장면을 해석할 때 이용자에게 맞는 전제를 두기 위해 씁니다("선택 안 함"을 고를 수 있습니다) |
| 생년월일 | 만 나이를 계산해 나이대에 맞는 배역·과제를 제안하고, 만 14세 미만의 가입을 막기 위해 씁니다 |
| 추구하는 방향 | 매체 연기와 무대 연기는 표현의 크기와 기준이 달라, 피드백의 기준을 정하기 위해 씁니다 |
| 연기 경력 | 설명의 깊이와 용어 수준을 경력에 맞추기 위해 씁니다 |
| 최종 목표 | 취미·오디션·전문 배우에 따라 연습 제안의 방향을 정하기 위해 씁니다 |

이름 외의 항목은 이용자 본인만 봅니다. 다만 이용자가 포트폴리오 공유 링크를 켜면 그 공개 페이지에 이름·프로필 사진·성별·만 나이가 함께 표시됩니다.

## 3. 선택 항목
- 프로필 사진, 한 줄 소개 — 설정에서 이용자가 직접 넣을 때만 수집합니다.
- 포트폴리오(소개글·경력·사진) — 이용자가 직접 적을 때만 수집합니다.

선택 항목을 넣지 않아도 서비스 이용에 제한이 없습니다.

## 4. 서비스를 이용하면서 생기는 정보
- 이용자가 올린 연기 영상과 음성, 대본, 리딩 녹음
- 분석 결과, 코치 대화, 연습 노트, 코치가 기억하는 연습 맥락
- 알림 수신을 위한 기기의 푸시 토큰과 알림 설정
- 서비스 이용 기록, 접속 로그, 기기 정보
- 웹 이용 분석을 위한 쿠키 기반 식별자와 방문 기록(Google Analytics)
- 서비스 안에서 수행한 동작의 기록과, 이용 화면을 재생 가능한 형태로 남기는 화면 기록(Amplitude)
- 오류가 났을 때 자동으로 남는 오류 기록(Sentry)

이용 목적: 분석과 코칭의 제공, 이용자가 어느 단계에서 어려움을 겪는지 파악해 기능을 고치는 일, 오류의 탐지와 복구. 위탁받는 회사, 국외 이전, 항목별 보관 기간과 거부 방법은 개인정보 처리방침에서 안내합니다.

영상에서 얼굴 표정·감정 등을 분석하는 일은 별도의 **AI 분석 동의**에 따릅니다.

## 5. 보유 및 이용 기간
- 회원인 동안 보유하며, **회원을 탈퇴하면 지체 없이 파기합니다.**
- 탈퇴 시 파기하는 것: 이메일, 이름, 프로필 사진, 한 줄 소개, 포트폴리오, 소셜 로그인 식별자, 로그인·푸시 토큰, 영상과 녹음(「탈퇴 후 영상·녹음 보관·활용」에 동의한 경우는 그 문서에 따릅니다).
- 탈퇴 후 개인을 알아볼 수 없게 가명처리하여 통계·연구 목적으로 남기는 것: 성별, 5세 단위 연령대(생년월일은 지웁니다), 추구하는 방향, 연기 경력, 최종 목표, 연습 기록과 코치가 기억하는 연습 맥락.
- 소셜 로그인 식별자는 복원할 수 없는 값(해시)으로 바꿔 탈퇴 후 3년 보관합니다. 쓰임은 「탈퇴 후 영상·녹음 보관·활용」 동의의 철회 요청에서 본인을 확인하는 것 하나뿐입니다.
- 백업에는 파기 전 데이터가 최대 30일 남을 수 있습니다.

## 6. 만 14세 미만 아동
서비스는 만 14세 미만 아동의 가입을 받지 않습니다. 가입 중 입력한 생년월일이 만 14세 미만이면 계정과 입력한 정보를 즉시 파기합니다.

## 7. 동의를 거부할 권리
이용자는 이 동의를 거부할 수 있습니다. 다만 위 1·2항은 서비스 제공에 꼭 필요한 항목이어서 동의하지 않으면 서비스를 이용할 수 없습니다. 가입한 뒤 이 동의를 거두는 방법은 회원 탈퇴입니다.
