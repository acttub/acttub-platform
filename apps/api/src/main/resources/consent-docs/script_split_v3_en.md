# Consent to Script Splitting (Required)

Effective Date: The date this version is published (shown on the sign-up consent screen and in the consent list in Settings)

This consent is **required**. Acttub provides practicing with your own script as a core feature, so this consent is needed to use the service.

## 1. What You Are Consenting To
When you paste a script or add one from a file, the **script text** is sent through our server to OpenAI's AI service (OpenAI API) so it can be split into characters, lines, and stage directions. If you add a file, we keep the **original file** in our storage.

## 2. What Is Sent and What Is Kept
- Sent to OpenAI: the script text (for a file, the text extracted from it). A long script is sent in several parts, each with the list of character names in that script.
- Kept in our storage: the original file, if you added one

We do not send anything that identifies you, such as your name or email, to OpenAI. We send requests with the setting that tells OpenAI not to store them.

## 3. Purpose
To split the script into characters, lines, and stage directions and save it for script reading. The original file is kept so the script can be read again when needed, and an original file that could not be read or split is kept to find and fix the cause of that failure. Nothing else.

## 4. Processors and Overseas Transfer
- Processor: OpenAI (OpenAI API) for script splitting
- Processor: Amazon Web Services (AWS) for storing original files
- Destination: overseas servers operated by each processor
- When and how: over an encrypted network each time you add a script
- See the Privacy Policy for the full list of processors and overseas transfers.

## 5. Retention
- A split script is kept until you delete it or withdraw from the service.
- An original file is kept with the script made from it and is deleted together when you delete that script or withdraw. Among original files that did not become a script, a file that could not be read or split is kept for one year to find and fix the cause and is then deleted; other original files (duplicates and so on) are deleted after one day. If you withdraw from the service, kept files are deleted too.

## 6. Changing Your Consent
Because this consent is required, it cannot be withdrawn while you are a member; to withdraw it, delete your account. When you delete your account, split scripts and original files are deleted. While you are a member, deleting a script also deletes that script and its original file.

## 7. Right to Refuse
You may refuse this consent. Because it is required, however, you cannot sign up for or keep using the service if you refuse.
