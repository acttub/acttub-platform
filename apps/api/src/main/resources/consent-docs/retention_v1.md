# 탈퇴 후 영상·녹음 보관·활용 동의 (선택)

시행일: 이 판이 발행된 날 (앱의 동의 화면과 설정의 동의 목록에 표시됩니다)

이 동의는 **선택**입니다. 동의하지 않아도 서비스의 모든 기능을 똑같이 이용할 수 있습니다.

## 1. 무엇에 동의하나요
회원을 탈퇴하면 이용자가 올린 연기 영상과 리딩 녹음은 **지체 없이 파기하는 것이 기본**입니다. 얼굴과 목소리는 개인을 알아볼 수 없게 만들 수 없기 때문입니다.

이 문서에 동의한 경우에만, 탈퇴한 뒤에도 영상과 녹음을 아래 목적과 기간으로 보관·활용합니다.

## 2. 보관·활용 목적
- 서비스 개선 — 분석과 코칭의 품질을 점검하고 고치는 데 씁니다.
- AI 모델 학습 — 연기 분석·코칭에 쓰는 AI 모델을 학습하고 평가하는 데 씁니다.

위 두 목적 밖으로는 쓰지 않으며, 외부에 공개하지 않습니다.

## 3. 보관 기간
탈퇴한 날부터 **3년**입니다. 기간이 끝나면 파기합니다. 더 보관하려면 다시 동의를 받습니다.

## 4. 동의를 바꾸는 방법
- **회원인 동안**: 설정의 동의 목록에서 언제든 동의와 거절을 바꿀 수 있습니다. 바꾼 즉시 저장되며, 탈퇴하는 시점의 결정에 따라 파기 여부가 정해집니다. 결정하지 않은 채 탈퇴하면 거절로 보고 파기합니다.
- **탈퇴한 뒤**: 개인정보 처리방침에 적힌 연락처로 철회를 요청할 수 있습니다. 같은 로그인 방식(Google·Apple·카카오·네이버)으로 로그인해 둔 계정과 대조하여 본인임을 확인한 뒤, 보관하던 영상과 녹음을 파기합니다.

## 5. 동의를 거부할 권리
이용자는 이 동의를 거부할 수 있고, 거부해도 어떤 불이익도 없습니다.
