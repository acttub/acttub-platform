# 코치 발화 자연화 + 연기 현장 용어 도입 설계

날짜: 2026-07-07
상태: 승인됨 (접근 B — 프롬프트 수정 + 가드 확장)

## 문제

코치가 1층 분석 데이터(타임스탬프, 피치 등 기술 서술)를 발화에 그대로 노출한다.

> "00:45-00:55 구간에서 '아' 대사를 낮은 피치로 말하며 … 낮은 피치로 말했어 — 이거 의도한 거야?"

AI 보고서처럼 들려 사람 코치의 느낌이 없다. 원인은 `prompt.py`의 RULES가
"'[시간] 관찰사실(수치)'로 물어라"라고 강제하는 것.

## 방향 (사용자 결정)

- **자연어로 녹여내기**: 발화에서 타임스탬프·기술 수치를 빼고 대사·행동 기준으로 지칭.
  시간값은 `focus_timestamp` 필드로만 전달 (UI 클립 표시용).
- **연기 현장 공용어 사용**: Confluence [연기 현장 용어 사전](https://hiws99.atlassian.net/wiki/spaces/TSSNN/pages/20643841)
  (TSSNN/20643841) 기준. 감정선·비트·사이·템포·톤·딕션·말끝 처리·호흡이 뜨다·
  소리가 먹다·붕 뜨다·시선 처리·미세 표정·서브텍스트·목적 등.
  - 영어 음차 새로 만들지 않음, 한국어 표기 그대로.
  - 시스템 내부 라벨(severity, dimension 등) 비노출.
  - 처음 쓰는 전문어는 1회만 살짝 풀어줌.
  - 추상 지시("감정 더 넣어") 금지 유지, 증상은 짚되 비난조 금지.

## 변경

### 1. `src/acting_agent/prompt.py` — RULES

- probe_intent: "[시간] 관찰사실(수치)" 문구 제거 → "사람 코치가 옆에서 본 것처럼
  관찰을 말로 그려주고 의도를 묻는다" + 예시 한 줄.
- 철칙의 "관찰한 사실(수치)", "시간 표시를 붙이고" 제거.
- 새 "말투 규칙" 블록 추가: 타임스탬프/기술 수치/내부 라벨 금지, 대사·행동 기준 지칭,
  현장 용어 목록, 1회 풀어주기, 추상 지시 금지, 비난조 금지.
- `focus_timestamp` 지시(마지막 줄)는 유지 — 기계 채널.

### 2. `src/acting_agent/guard.py` — 이중 방어

- 타임스탬프 정규식 `\d{1,2}:\d{2}` 추가.
- 기술 용어 금지어 추가: 피치, 데시벨, 헤르츠, 구간, Hz, dB, severity.
- 기존 `has_forbidden` → `engine._generate` 재시도 루프가 그대로 잡음.

### 3. 테스트

- `tests/test_guard.py`: 타임스탬프 허용 assert 뒤집기, 기술 용어 케이스 추가,
  자연어 발화 허용 케이스 추가.
- `tests/test_coach_prompt.py`: 말투 규칙이 프롬프트에 실리는지 assert 추가.
  (anomaly 블록의 시간·severity는 입력 데이터라 그대로 유지.)

## 범위 밖

- summary/anomaly 스키마 변경 없음 (1층 데이터는 그대로, 노출만 차단).
- 반말 톤 유지 (기존 결정).
