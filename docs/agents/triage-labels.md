# 트리아지 라벨

스킬들은 다섯 개의 표준 트리아지 역할로 말합니다. 이 표가 그 역할을 이 레포에서 실제로
쓰는 라벨 문자열로 연결합니다.

| mattpocock/skills 라벨 | 우리 트래커 라벨  | 의미                                   |
| ---------------------- | ----------------- | -------------------------------------- |
| `needs-triage`         | `needs-triage`    | 메인테이너가 평가해야 하는 이슈        |
| `needs-info`           | `needs-info`      | 제보자의 추가 정보를 기다리는 중       |
| `ready-for-agent`      | `ready-for-agent` | 명세가 충분해 AFK 에이전트가 맡을 수 있음 |
| `ready-for-human`      | `ready-for-human` | 사람이 구현해야 함                     |
| `wontfix`              | `wontfix`         | 처리하지 않음                          |

스킬이 역할을 언급하면(예: "AFK 준비 라벨을 붙여라") 이 표의 오른쪽 문자열을 씁니다.

## 이 레포에서의 적용 방식

Jira 이슈의 **Labels 필드**에 붙입니다. **에이전트는 Jira에 직접 쓰지 못하므로**
어느 라벨을 붙일지 판단해 사람에게 요청합니다(→ [issue-tracker.md](./issue-tracker.md)).

주의할 점:

- **Jira 라벨은 자유 텍스트라 오타가 그대로 새 라벨이 됩니다.** 요청할 때 위 표의 문자열을
  글자 그대로 적어 주세요. 임의로 `ready_for_agent` 같은 변형을 만들지 않습니다.
- 다섯 개는 **상호 배타적**입니다. 새로 붙일 때 기존 트리아지 라벨을 떼는 것도 함께 요청합니다.
  (예: `needs-info` → 정보가 들어오면 `needs-info`를 떼고 `ready-for-agent`를 붙입니다.)
- 트리아지 라벨과 **Jira 상태**(`In Progress` / `검토 중` / `Done` / `보류 중`)는 별개 축입니다.
  라벨로 상태를 바꾸려 하지 말고, 상태 전이는 아예 건드리지 않습니다.
- 이 다섯 개 외의 라벨(도메인 분류 등)은 사람의 영역입니다. 에이전트가 새 라벨 어휘를
  만들어내지 않습니다.

오른쪽 열은 실제로 쓰는 어휘에 맞춰 언제든 고쳐도 됩니다.
