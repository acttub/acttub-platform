# 트리아지 라벨

스킬이 트리아지 역할을 말하면 아래 문자열을 Jira **Labels** 필드에 그대로 사용하도록
사람에게 요청합니다. 이 다섯 라벨은 상호 배타적입니다.

| 라벨 | 붙이는 조건 |
|---|---|
| `needs-triage` | 메인테이너의 평가가 필요함 |
| `needs-info` | 제보자의 추가 정보를 기다림 |
| `ready-for-agent` | 명세가 충분해 에이전트가 구현할 수 있음 |
| `ready-for-human` | 사람이 구현해야 함 |
| `wontfix` | 처리하지 않기로 결정함 |

## 적용

1. 현재 붙은 다섯 라벨 중 하나가 있는지 확인합니다.
2. 기존 트리아지 라벨을 제거하고 새 라벨 하나를 정확한 문자열로 붙이도록 함께 요청합니다.
3. Jira 상태(`In Progress` / `검토 중` / `Done` / `보류 중`)는 별도 축으로 둡니다.

에이전트가 Jira에 직접 쓰지 않는 경계는 [issue-tracker.md](issue-tracker.md)를 따릅니다. 도메인
분류처럼 이 표 밖의 라벨 어휘는 사람이 정합니다.

**완료 기준:** 다섯 라벨 중 정확히 하나만 남고, Jira 상태와 다른 라벨은 바뀌지 않습니다.
