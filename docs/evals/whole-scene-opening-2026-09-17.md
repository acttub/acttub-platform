# 전체 장면 우선 첫 질문 회귀 수정

338→339 비교에서 공통 정책이 ‘필요할 때 구체적인 대사를 짚는다’에서 ‘첫 턴에 특정 대사의 이유를 묻는다’로 강화됐다.
2층과 공통 첫 응답 정책을 전체 흐름 파악 → 중요한 분석 쟁점 선정 → 필요한 대사를 근거로 사용하는 순서로 수정했다.
전체를 보라는 것은 긴 줄거리 요약을 출력하거나 모든 발화를 나열하라는 뜻이 아니다.

검증: OpeningQuestionTest, StructuredCoachEngineTest, DialogueStateTest 22개 통과.
합성 실제 모델 analysis-unknown 사례 구조 검사 통과. 첫 질문은 짐·과거 사건·열쇠 요구를 함께 다뤄 범위는 넓어졌다.
하지만 ‘이 말들이 어떻게 이어지나요’처럼 분석 부담을 배우에게 넘기고, 모름 뒤 이유 재질문·관계 해석의 추정이 남았다.
따라서 의미 품질이 통과한 결과로 보지 않는다. 실제 사용자 영상을 전송하지 않았다. 배포 전 추가 검토가 필요하다.
