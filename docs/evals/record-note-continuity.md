# 1층 기록과 3층 노트의 대화 연속성

## 변경 이유

2층은 장면 전체의 말하는 이유·목표를 `focus.basis=scene`으로 다룰 수 있지만,
3층은 영상의 표현 관찰과 별도의 배우 방향이 있어야 연습을 제안할 수 있었다.
장면 분석을 마친 대화가 노트에서 표현 교정으로 바뀌거나 연습 없이 끝나는 불일치를 수정한다.

## 1층

- 대사 전체와 부정·조건·정정·호칭·말의 이어짐을 보존한다.
- 대사 속 사건과 실제 영상의 사건, 원문과 숨은 의도 추정을 구분한다.
- 청크의 원본 내 위치와 원본 길이를 제공하되 출력 시각은 청크 상대 시각을 유지한다.
- 녹음된 크기를 발성 문제로, 화면 밖 움직임을 행동 부재로 판정하지 않는다.
- 출력 계약은 유지한다. 새로운 의도·진단 필드를 만들지 않는다.

## 3층

- 장면 분석은 현재 배우 방향 또는 배우가 직접 정리한 인물 목표와 대사/관찰로 연습을 만든다.
- 표현 연습은 여전히 실제 영상 관찰을 요구한다. 대사나 확인 한계만으로 표현을 평가하지 않는다.
- 2층의 유효한 제안을 이어가고 배우가 거절·정정한 방법은 되살리지 않는다.
- 아직 뜻을 모르거나 방법 제안을 원하지 않으면 연습 없이 확인된 내용만 남긴다.
- 인물 대사는 `장면 대사`로 표시한다. 배우 경험·성과로 바꾸지 않는다.
- 전체 초점의 연습 근거는 앞뒤 구간을 유지하며 공개 노트의 구간도 단일 대사로 줄이지 않는다.
- 모델 실패 시 현재 배우 목표를 보존하고 과제를 지어내지 않는다.
- 과거 기록은 `basis`가 없으면 기존 표현 기준을 적용한다. 공개 응답 필드는 유지한다.

## 검증

회귀 테스트: coaching/report/observation 패키지. 실제 모델 테스트는 환경 변수가 없으면 별도로 건너뛴다.

실제 모델: `live_coach_eval=true`, `eval_suite=note`로 수동 실행한다.
실제 사용자 자료 없이 합성 인계 기록 8개를 기존 dev 텍스트 모델에 전달한다.

1. 장면 전체의 정정된 인물 목표 → 분석 연습
2. 배우가 수용한 방법 → 같은 방법 유지
3. 방법 제안 거절 → 연습 없음
4. 아직 모르는 목표 → 연습 없음
5. 이후 정정에 의해 철회된 목표 → 이전 목표 되살리지 않음
6. 서버 실패 종료 → 연습 없음
7. 잘된 표현 유지 → 강제 결함·반대 처방 없음
8. 손이 안 보이는 영상 → 손동작 교정 없음

자동 검사 통과만으로 의미 품질을 확정하지 않는다. 저장된 요약·연습을 함께 검토한다.
이 평가는 3층 텍스트 출력 평가이며 1층 Gemini의 실제 영상 인식 품질 평가는 포함하지 않는다.
