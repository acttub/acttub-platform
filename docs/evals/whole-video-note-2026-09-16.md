# 전체 초점에서 다음 촬영까지의 합성 평가

## 범위
실제 사용자 데이터 없이, 12초 합성 기록의 세 문장에 동일한 끝말 음량 감소 관찰을 넣었다. 기록 조립 → 2층 실제 모델 대화 → 종료 handoff → 3층 실제 모델 노트 → 공개 노트 변환을 실행했다. 원본 영상에서 1층이 올바르게 추출하는지는 검증하지 않았다.

## 결과
- 관련 결정적 테스트 24개 통과.
- 실제 모델 대화와 노트 생성 2회 구조 검사 통과.
- 최종 초점은 whole_video / recurring으로 유지되고 세 구간의 관찰을 인용했다.
- 최종 연습: “세 문장 모두 앞부분의 소리를 유지해 마지막 두 음절까지 상대에게 닿게 말해 보세요. 소리를 키우거나 지르지는 마세요.”
- 확인 기준: “세 문장 모두 끝 두 음절이 앞부분처럼 들리는지 장면 전체에서 확인합니다.”
- 배우의 ‘소리를 지르고 싶지 않다’는 정정을 연습에 반영했다. 실제 실행·성공으로 기록하지 않았다.

## 남은 품질 문제
후속 프롬프트를 보완한 뒤에도 중간에 “세 문장 중 어느 끝말을 가장 분명히 남기고 싶나요?”라는 불필요한 선택 질문이 나왔다. 최종 초점과 연습은 전체 범위를 유지했지만, 2층 질문 품질이 해결됐다고 판정하지 않는다. 자동 검사는 JSON·상태·연결을 검증하며 대화 의미 품질의 합격 판정이 아니다.

1층 지시는 이미 전체 구간, 유지·변화, 확인 한계를 요구한다. 이번 결과만으로 실제 1층 관찰 품질이 충분하다고 결론 내릴 수 없으므로 변경하지 않았다. 실제 영상 다양성, 변화형 초점, 반례가 있는 기록은 추가 평가 범위다.

전체 API 로컬 테스트는 애플리케이션 컨텍스트 초기화 실패로 미통과했다. Docker 명령이 없는 환경이며 통합 검증은 PR CI 결과를 확인해야 한다.
