# Gemini 영상 직접 대화 실험

`/practice/direct-video`에서 영상을 올리고 지정된 공통 코칭 지침으로 Gemini와 대화한다.
1층 영상 기록 생성과 기존 연습 세션 생성은 호출하지 않는다.

- 서버의 `SITE_URL=https://dev.acttub.com`에서만 API가 활성화된다.
  `ACTTUB_DIRECT_VIDEO_ENABLED=false`로 끌 수 있다. 운영 주소에서는 이 값을 true로 해도 열리지 않는다.
- 서버의 `GEMINI_API_KEY`와 `GEMINI_MODEL`을 사용한다. 키와 Gemini 파일 주소는 브라우저에 보내지 않는다.
- 첫 응답과 후속 응답 모두 `DirectVideoPrompts.common()`의 지정된 프롬프트만 사용한다.
  응답 유형 분류·유형별 프롬프트·자동 대화 시작 문구를 추가하지 않는다. 1층 분석 호출은 없다.
- 전체 대화 이력이 맥락을 대신하며 별도 상태·배우 기억을 프롬프트에 덧붙이지 않는다.
  이 실험은 입력 경로와 모델을 함께 바꾸므로 1층 유무만의 효과를 분리하는 실험은 아니다.
- 영상은 Gemini Files API에 한 번 올리고, 매 호출에 파일 참조와 전체 대화를 전달한다.
  영상 참조 재사용은 모델의 영상 입력 토큰 비용이 없어졌다는 뜻이 아니다.
- MP4/MOV/WebM/MPEG 최대 50MiB. 대화당 코치 응답 최대 10회, 시작 후 30분.
  기존 로그인/게스트 인증·AI 분석 동의·요청 제한을 적용하고, 소유자만 읽고 쓸 수 있다.
- 동시 실험은 사용자당 2개, 서버 전체 12개다. 업로드 후 처리와 답변은 비동기로 진행한다.
- 실험 세션과 대화는 서버 메모리에만 있다. 새로고침하면 화면에서 사라지고,
  서버 재시작 시 복구되지 않는다. UI에서 텍스트로 내려받아 비교한다.
- 업로드 임시 파일은 Gemini 전송 작업 종료 시 제거한다. Gemini 파일은 대화 닫기·만료·
  첫 응답 실패 시 삭제를 요청한다. 프로세스 강제 종료나 외부 삭제 실패까지 즉시 삭제를 보장하지 않는다.
- 3층 노트와 배우 기억 갱신은 이 실험에 포함하지 않는다.

## 임시 dev API

정식 API 스키마에 포함하지 않는 실험용 경로다. 기존 소비자의 계약은 바꾸지 않는다.

| 요청 | 동작 |
|---|---|
| POST `/v2/coach/direct-video` | multipart의 `video` 업로드, 202와 세션 반환 |
| GET `/v2/coach/direct-video/{id}` | 처리 상태와 완료된 대화 조회 |
| POST `/v2/coach/direct-video/{id}/messages` | `{text}` 전송, 202 반환 |
| DELETE `/v2/coach/direct-video/{id}` | 실험 세션 종료, 204 반환 |

응답 실패 시 사용자 발화도 확정 이력에 추가하지 않는다. 화면은 입력을 보존해 재시도할 수 있게 한다.
진행 중 중복 발화는 409, 다른 사용자/없는/만료된 세션은 404다.

## 비교할 것

같은 영상과 같은 배우 응답으로 기존 dev 대화와 비교한다. 첫 질문의 적절성,
대사·표정·동작의 오독, 정정 반영, 반복 질문, 응답 시간과 입력 비용을 본다.
