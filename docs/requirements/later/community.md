# 커뮤니티 (1.0.0 범위 밖, 후속 보관)

2026-09-17 계정 요구사항 검토에서 커뮤니티(게시판)를 1.0.0에서 빼기로 했다. 후속에서 이을 수 있도록
그때까지 정해진 요구사항과 결정을 여기 둔다. 현재 코드(`apps/api` community 기능, 웹 `/community`,
앱 게시판 탭)와 디자인(A3·A3.1·A3.2, D11·D12·D15, WC·WC2·WC3)은 그대로 있다.

## 보관하는 결정

- 작성자 이름은 프로필 이름(account.profile)이다. 별도 닉네임은 없다. 이름을 바꾸면 이미 쓴 글·댓글도
  현재 이름으로 보인다. 글에 이름을 복사해 두지 않는다.
- 탈퇴하면 글·댓글 행은 남기고 작성자만 "탈퇴한 사용자"로 보인다. 지우면 남의 글타래가 깨지기
  때문이다(ADR-029). 탈퇴 화면 안내에도 이 문장이 들어간다.
- 차단은 사람 단위 user_blocks이며 챌린지와 같은 테이블을 쓴다.
- 웹 게스트(account.guest)는 읽기만 하고 글쓰기는 회원만이다.
- 익명 글, 분류별 목록, 좋아요·신고는 현재 코드 구조를 따른다. 신고 사유는 spam·abuse·sexual·
  privacy·other다.

## 후속에서 정할 것

- community_* 테이블 7개를 1.0.0에서 남길지(데이터 보존) 지울지.
- 연습·리포트와 데이터가 이어지지 않는다는 원칙(CONTEXT.md의 Community)을 유지할지.
