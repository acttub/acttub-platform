## 앱 공지를 띄우는 방법

앱 공지는 [app.poster](../app/poster.md)의 서버 공지 포스터(`app_posters` 표)다. 앱 업데이트 없이 운영 API 로 넣는다.
**이 PR 은 넣지 않는다** — 운영 반영은 따로 승인을 받고 한다.

- 경로: `POST /v2/admin/posters`, 헤더 `Authorization: Bearer $ADMIN_OPS_TOKEN`(그 서버에 `ADMIN_OPS_TOKEN` 이 설정돼 있어야 경로가 있다).
  넣은 뒤 `GET /v2/admin/posters` 로 확인하고, 고칠 때는 `PATCH /v2/admin/posters/{id}`, 끌 때는 `active=false` 다(지우는 경로는 없다).
- 넣을 값(제안):

```json
{
  "slug": "terms-billing-2026-11",
  "active": true,
  "priority": 20,
  "starts_at": "2026-10-26T00:00:00+09:00",
  "ends_at": "2026-11-15T00:00:00+09:00",
  "platforms": ["ios", "android"],
  "locale": "ko",
  "min_app_version": null,
  "frequency": "once",
  "audience": "all",
  "dismissible": true,
  "badge": "공지",
  "title": "약관 개정과 11월 결제 안내",
  "body": "이용약관과 개인정보 처리방침이 10월 27일부터 바뀌어요.\n1.1.0 업데이트(11월 1일)부터 Pro 결제를 시작해요. 월 3,900원, 연 32,500원이에요.\n11월 1일부터 무료로는 코칭 하루 1회, 리딩 대본 1개 보관까지 쓸 수 있어요.\n10월 26일까지 가입했다면 11월 30일까지 Pro를 무료로 써요. 카드 등록이 없어 자동 결제되지 않아요.\n리딩 고품질 목소리는 10월 31일까지 무료이고, 11월 1일부터는 Pro 혜택이에요.",
  "cta_label": "자세히 보기",
  "cta_action": "url",
  "cta_target": "https://acttub.com/pricing"
}
```

- 값의 이유: `priority` 20 은 첫 포스터 `cloud-voice-launch`(10)보다 먼저 보이게 한다. `frequency` `once` 는 한 번만 보인다(모두에게 한 번은
  보여야 하면 `daily` 로 바꾼다). `min_app_version` 을 비워 지금 깔린 모든 앱 판에 보낸다. `locale` `ko` 라 영어로 쓰는 앱에는 가지 않는다 — 영어 공지가
  필요하면 같은 slug 의 `locale: "en"` 행을 따로 넣는다. 본문의 줄바꿈(`\n`)은 앱에서 그대로 보인다.
- 함께 볼 것: `cloud-voice-launch` 포스터는 2026-12-01 에 끝나도록 돼 있고 버튼이 「무료로 켜기」다. 11월 1일부터 고품질 목소리가 Pro 혜택이 되면
  이 포스터를 10월 31일에 끄거나(`active=false`) 문구를 바꿔야 한다.
