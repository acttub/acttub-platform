# 앱 공통

[쓰는 법](../README.md)과 [공통 규칙](../common.md)을 먼저 읽는다.
특정 기능 영역에 속하지 않고 앱 전체에 걸친 화면 요소를 둔다. 홈 진입 때 띄우는 공지 포스터와 오디션 공고 모아보기가 있다.
운영자가 서버 데이터만 바꿔 앱 업데이트 없이 내용을 바꾸는 것이 이 영역의 목적이다.

## 용어

| 용어 | 뜻 | 피할 말 |
|---|---|---|
| Poster (공지 포스터) | 홈 진입 때 전체 화면으로 띄우는 공지 한 장. 서버의 `app_posters` 한 행이고 slug 와 언어로 가린다. | 팝업(수식 없이), 배너, 광고, 프로모션(코드 이름으로) |
| Revision (판) | 포스터 내용의 판 번호. 올리면 기기에 남은 "봤음·다시 보지 않기" 가 무효가 되어 다시 보인다. | 버전(앱 판과 헷갈릴 때) |
| Audition posting (오디션 공고) | 외부 출처에서 모은 배우 모집 공고 한 건. 서버의 `audition_postings` 한 행이고 (source, source_ref)로 가린다. | 캐스팅 콜, 구인글, 채용공고(코드 이름으로) |
| Source (출처) | 공고를 모아 오는 사이트 하나. 코드(`otr` 등)와 등급이 있다. | 소스 사이트, 채널 |
