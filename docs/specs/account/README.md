# 계정

[쓰는 법](../README.md)과 [공통 규칙](../common.md)을 먼저 읽는다.

## 용어

코드·문서·이슈에서 쓰는 이름이다. 규칙은 각 기능 파일이 정본이고, 여기에는 뜻과 피할 말만 둔다.

| 용어 | 뜻 | 피할 말 |
|---|---|---|
| Account (계정) | users 행 하나. Member와 Guest 모두 계정이며, 탈퇴한 뒤에도 행은 남는다. | 유저, 회원(게스트를 포함할 때) |
| Member (회원) | 제공자(구글·애플·카카오·네이버) 로그인으로 만든 계정. 앱에서만 생긴다. | 사용자(게스트와 가를 때), 가입자, 로그인 사용자 |
| Guest (게스트) | 웹이 로그인 없이 만든 계정. 회원도 웹에서는 게스트다(ADR-028). | 익명 사용자, 비회원, 임시 계정, 체험 계정 |
| Transfer (이관, 옮기기) | 게스트의 자료를 회원 계정으로 주인을 바꿔 옮기는 것([account.guest](guest.md)). | 마이그레이션, 동기화, 연동, 계정 병합, 계정 연결 |
| Gate (게이트) | 회원이 동의와 프로필 필수 항목을 마쳐야 열리는 문. 그 안의 기능을 **보호 기능**이라 부른다. 게이트 밖 경로는 [공통 규칙](../common.md#게이트와-보호-기능)이 정본이다. | 온보딩, 인터셉터, 진입 조건 |
| Consent Document (동의 문서) | 동의를 받는 문서의 한 판. 개인정보 처리방침은 동의 문서가 아니라 고지다. | 약관(수식 없이 — 이용약관은 그중 하나), 정책, 이용 동의 |
| Profile (프로필) | 가입 게이트에서 배우가 직접 적는 값([account.profile](profile.md)). 연습에서 뽑아내는 Actor Memory와 다르다. | 포트폴리오, 배우 정보, 닉네임, 호칭 |
| Portfolio (포트폴리오) | 배우가 오디션에 내려고 직접 적는 소개글·경력·사진과 그것을 보여 주는 공유 링크. 캐스팅하는 사람이 읽는다(ADR-030). | 프로필, 이력서, 배우 정보, 경력 사항 |
| Withdrawal (탈퇴) | 회원이 계정을 닫는 것. 행은 지우지 않고 사람을 알아보게 하는 것만 파기한다(ADR-029). 재가입은 새 계정이다. | 계정 삭제, 삭제, 비활성화(수식 없이), deactivate |
| Identity Hash (신원 해시) | 탈퇴한 계정의 제공자 신원에서 만든 해시. 같은 제공자 계정이 다시 오는지만 알려 준다([account.withdraw](withdraw.md)). | 익명 ID, 탈퇴자 ID, 지문 |
