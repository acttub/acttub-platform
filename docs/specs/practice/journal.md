# practice.journal 배우 일지
- 도입: 1.0 개편 (SOMA-720)
- 화면: pen ⑧ 「배우 일지 질문 1~4 / 4」, 「배우 일지(노트) · 완성 (요약형)」, 「배우 일지 · 편집」, 「오늘 코칭 끝」, ⑫ 「ⓑ6 배우 일지 (막힌 곳 풀기)」·「ⓒ4 배우 일지 (인물 이해하기)」
- 테이블: actor_journals

## 기능
코칭을 마치면(정리 카드의 「일지 쓰고 마치기」, 목적 없는 코칭은 대화가 닫힐 때) 채팅을 벗어나 별도 화면에서 고정 질문 4개를 묻는다.
각 질문은 선택지나 직접 쓰기로 답하고 건너뛸 수 있다. 4번째의 「일지 만들기」를 누르면 서버가 코칭 대화로 자동 칸(오늘 한 연습·장면과 인물·
받은 피드백과 영상 시간)을 만들고, 배우의 답은 고치지 않고 그대로 넣는다. 완성 일지는 요약형(10/19 채택)이고 「편집」으로 고칠 수 있다.
「저장하기」 뒤 「오늘 코칭 끝」을 보이고 홈으로 간다. 연습 기록에서 그 회차를 다시 열면 같은 일지 화면이다.

## 의도
느낌·아직 모르는 것·다음 선택·후기는 영상이나 대화로 알 수 없어 배우에게 묻고, 대화로 정리할 수 있는 것은 묻지 않는다. 배우가 쓴 글은
AI 가 바꾸지 않는다.

## 목적
코칭이 끝날 때 배우가 오늘 한 것과 다음에 할 것을 자기 말로 남기고, 다음 연습(홈 숙제·연습 알림)이 그것을 이어받게 한다.

## 입력·출력
- `POST /v2/practices/{practice_id}/journal` — `answers`(feeling{choice,text}·unknown{none,text}·next{undecided,text}·review, 건너뛴 질문은 null).
  새로 만들면 201, 이미 있으면 다시 만들지 않고 200.
- `GET /v2/practices/{practice_id}/journal` — 일지.
- `PUT /v2/practices/{practice_id}/journal` — 배우 답 전체 + 자동 칸 전체(practice·character·feedback). 글이 빈 줄은 지운다.
- 응답: answers, draft_status, practice[{text,basis}], character[{aspect,text}], feedback[{text,giver,at}], 머리 줄용 title·purpose·role_name.

## 상태
pending(자동 칸 만드는 중) → ready(만듦) / failed(두 번 실패, 배우 답만) / skipped(대화가 없어 만들지 않음). 배우가 고치면 edited_at 이
찍히고, 그 뒤엔 늦게 끝난 생성이 일지를 덮지 않는다. 고칠 때 pending 이던 일지는 ready 가 된다.

## 규칙·제약
- 질문 문구와 순서는 늘 같다(해 보니 어땠어요? · 아직 헷갈리거나 궁금한 게 있어요? · 다음엔 뭘 해 볼래요? · 오늘 연습을 한 줄로 남긴다면?).
- 배우의 답과 자동 칸은 따로 저장한다. 자동 칸을 만들거나 고쳐도 배우의 답을 덮지 않는다. 글은 앞뒤 공백만 걷는다.
- 자동 칸 프롬프트는 `coaching/journal-create.txt`(10/19 채택 v4)이고, 모델 답은 v4 검사 규칙으로 항목마다 걸러 근거가 맞지 않는 항목을
  버린다(근거 없는 칸은 빈 칸). 영상 없는 회차엔 영상 근거와 영상 시간을 쓰지 않는다.
- 모델은 연습 노트와 같은 생성기(노트용 키)를 쓰고, 실패하면 한 번 재시도한다. 그래도 실패하면 배우 답만으로 저장한다.
- 한 회차에 일지 하나. 본인만 읽고 고친다.
- 완성 일지: 위 상자(후기·느낌 태그·아직 모르는 것 N개) → 다음에 해 볼 것 → 한 줄 미리보기 목록(액티가 본 장면·오늘 한 연습·해 보니·
  장면과 인물·아직 모르는 것), 누르면 펼침. 빈 칸과 「없어요」·「아직 안 정했어요」는 숨긴다. 인물 이해하기는 장면과 인물이 맨 위다.
- 「다음에 해 볼 것」(질문 3에 직접 쓴 글)이 있으면 홈 숙제·코칭 탭·프로필의 다음 테이크 문장과 코칭 숙제 알림이 노트 제안보다 먼저 쓴다.
- 코칭 평가(도움 됐어요/아쉬웠어요)는 「오늘 코칭 끝」에서 받고 지금처럼 그 회차의 노트에 남긴다(practice.note).
- 탈퇴하면 일지를 지운다.

## 예외
- 없는 회차·남의 회차의 생성: 404 practice_not_found. 일지가 없거나 남의 것: 404 journal_not_found.
- 글 길이(답 300자, 편집 줄 200자)·줄 수(종류마다 5개) 초과는 422.
