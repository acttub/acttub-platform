# 챌린지

[쓰는 법](../README.md)과 [공통 규칙](../common.md)을 먼저 읽는다.
챌린지는 대사 한 줄과 기간이다. 배우들이 같은 대사를 연기한 영상을 올리고, 서로의 영상을 보고 좋아요·댓글을 남기며, 좋아요순
랭킹을 본다. 제품에서의 자리는 리텐션이다(PRD 부가 기능). 회원·앱 전용이고 웹 게스트에게는 없다(account.guest). 한국어 사용자에게만
탭·직접 진입·푸시가 열린다(현행, 대사가 모두 한국어라). 서버 도메인은 이번에 처음 생기고 앱은 목업을 실제 API로 바꾼다. 영상은 연습과
같은 videos를 쓴다(practice.record).
공유 미리보기(`GET /v2/public/**`)와 운영 경로(`/v2/admin/**`)를 뺀 챌린지 경로는 게이트(동의·프로필)를 마친 회원이
`X-Acttub-Client: app/...`로 보낸 한국어 요청에만 열리고, 게스트·웹·다른 언어는 403 member_only다.

연기를 채점하지 않는다는 원칙(ADR-005)은 여기서도 같다. 좋아요 랭킹은 사람들의 반응 수를 세운 순서이며 ADR-005의 명시적 예외
(2026-09-21 개정)다([challenge.browse](browse.md)). AI 리포트는 관찰과 표현 차이의 설명이라 평가를 내지 않는다(거절 기준은
[challenge.ai-report](ai-report.md#규칙제약)). 공개 참여작·댓글·사용자 개설은 다른 사람이 보는 콘텐츠라 신고([challenge.report](report.md))와
사람 차단([challenge.block](block.md))을 함께 둔다. 계정 정지는 없고 운영 숨김이 그 자리를 맡는다. (ADR-032)


## 용어

| 용어 | 뜻 | 피할 말 |
|---|---|---|
| Challenge (챌린지, 목록에서는 "대사") | 대사 한 줄과 기간. | 이벤트, 미션, 게시판 |
| Entry (참여작) | 챌린지의 대사를 연기한 영상 하나를 올린 것. Video를 참조한다. | 게시물, 포스트, 영상(자산과 헷갈릴 때) |
| Ranking (랭킹) | 한 챌린지의 공개 참여작을 좋아요 수로 세운 순서. 사람들의 반응이며 연기 평가가 아니다. | 점수, 등급, 순위표(평가를 뜻할 때) |
| Challenge Report (AI 리포트) | 참여작을 같은 대사의 다른 공개 참여작들과 나란히 놓고 내 영상의 관찰과 차이를 설명하는 기록. 연습의 연습 노트와 다르다. | 분석 결과, 평가, 채점, 연습 노트 |
| Report (신고) | 회원이 참여작·댓글·챌린지를 사유와 함께 운영에 알리는 것. 위반 확정이나 차단을 뜻하지 않는다. | 차단, 리포트(AI 리포트와 헷갈릴 때는 영어를 쓰지 않음), 운영 숨김(결과를 가리켜) |
| Block (차단) | 회원이 다른 회원을 자기 화면에서 지우는 것. 운영 숨김·계정 정지와 다르고 신고를 대신하지 않는다(ADR-032). | 정지, 밴, 신고(차단을 가리켜), 운영 숨김 |
| Inbox (알림함) | 챌린지에서 온 알림이 쌓이는 곳. | 알림 설정(토글을 가리켜), 피드 |

## 챌린지 자료의 삭제·탈퇴

| 대상 | 참여작 삭제(본인) | 운영 숨김·챌린지 검토 | 탈퇴 |
|---|---|---|---|
| challenges | 그대로(주최자의 챌린지 삭제는 challenge.create) | moderation hidden·review(기간 상태는 별개, 자식 상태는 바꾸지 않고 노출만 막음) | host_user_id NULL, origin은 member 그대로(행·기간·참여작 유지) |
| challenge_entries | status deleted(행 유지, 캡션 파기, video_id NULL로 참조 해제), 랭킹·피드·프로필에서 제외 | status hidden_by_report(작성자의 공개 선택은 그대로 보존) | visibility private(행 유지, 집계·표본에서 제외, 재공개 불가) |
| entry_likes | 그 참여작의 행 삭제 | 그대로(현재 집계에서만 제외) | 탈퇴자가 남긴 좋아요는 남는다(집계 유지) |
| entry_saves | 그 참여작의 행 삭제 | 그대로(목록에서만 감춤, 비공개도 같음) | 탈퇴자의 저장 행 삭제(개인 북마크) |
| entry_comments | 그 참여작의 행: 본문 파기, deleted_at | 운영 숨김은 status hidden | 남기고 "탈퇴한 사용자"로 보임 |
| entry_reports | 행 유지, 그 참여작과 그 댓글에 대한 신고의 target_text를 비움(보관 기간은 challenge.report) | 그대로 | 그대로(신고자 신원은 계정 참조만) |
| entry_ai_reports | 본문·비교 자료 파기, 생성 이력만 남김(보관 기간은 challenge.ai-report) | 그대로(작성자는 봄) | 본문·비교 자료 파기, 생성 이력만 남김 |
| ai_jobs(challenge_report) | 진행 중 작업 failed/cancelled | 그대로 | 진행 중 작업 failed/account_deactivated([공통 상태](../common.md#공통-상태)) |
| user_blocks | 그대로 | 그대로 | 탈퇴자가 건 차단·받은 차단 행 삭제 |
| notifications | 그 참여작에 관한 것 삭제 | 그대로(대상은 이용 불가 안내) | 수신자 탈퇴면 행째 삭제, 행동한 사람이 탈퇴면 "탈퇴한 사용자" |
| 녹음·영상 객체 | 영상은 보관함에 남음(practice.library) | 그대로 | practice.record의 탈퇴 규칙(파기·보관 동의 3년). 보관 동의로 남은 파일은 챌린지 공개·표본에 다시 쓰지 않는다 |

게스트는 챌린지를 쓰지 않으므로 이관에 챌린지 자료가 없다. 목업의 예시 인물·참여작·숫자는 운영 자료로 옮기지 않는다. 탈퇴 열은
[account.withdraw](../account/withdraw.md)의 탈퇴가 한 번에 일으킨다. 탈퇴한 작성자를 어떻게 보이는지는
[공통 규칙 「탈퇴·삭제」](../common.md#탈퇴삭제)다. 챌린지·참여작·댓글은 행을 지우지 않고 삭제 표시로 남겨 요청 이력·한도 계산이
사라지지 않게 한다.

## 요청의 순서와 재전송

개설·참여·댓글·신고·AI 리포트 요청은 request_id를 싣고 [요청 재전송](../common.md#요청-재전송) 규칙을 따른다. 같은 요청의 재전송이
행·알림·AI 비용을 두 번 만들지 않는다. 유일 범위는 기능마다 적는다. 좋아요·저장·차단은 요청 id 없이 (대상, 사람) 유일인 연결 행이라
켜고 끄기가 멱등이다. 같은 대사 동시 개설, 삭제와 첫 참여, 신고 임계값 동시 도달, 탈퇴·차단과 겹친 반응은 모두 하나씩 순서를 갖고
판정된다(결과는 각 기능, 잠금은 [CONTRACT](../../../apps/api/CONTRACT.md) §6-16~§6-18). 개설·삭제·참여·좋아요·저장·댓글·신고·차단·AI
리포트 요청은 탈퇴가 먼저 끝났으면 [탈퇴와 겹친 쓰기](../common.md#탈퇴와-겹친-쓰기)대로 403 account_deactivated다.

## 노출 조건

노출 조건은 둘로 나눈다. **공개 조건**(참여작 public·visible, 작성자 활성, 챌린지 moderation visible, 영상 파일 있음)은 전체 집계·순위·표본
선정의 기준이고, **개인 노출 조건**(공개 조건 + 보는 사람과 작성자 사이 차단 없음)은 목록·피드·검색·반응의 기준이다. 본인 기록(P03·본인
댓글)은 예외 조회다. 댓글의 개인 노출 조건은 부모 참여작이 보이고, 댓글이 visible이며 deleted_at이 없고, 댓글 작성자와 차단이 없는 것이다.
다른 사람에게 보이는 것은 [account.profile](../account/profile.md#규칙제약)대로 현재 프로필 이름뿐이고, 챌린지의 아바타는 이름 첫 글자다.
