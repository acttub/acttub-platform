# 참고: Telta Interview Pro 랜딩 페이지

- URL: https://www.telta.ai/interview-pro
- 성격: AI 기반 채용 면접 지원 솔루션(B2B)의 랜딩 페이지. Acttub 랜딩/인터뷰 UI 설계 시 구조·톤 참고용.
- 확인일: 2026-07-12

## 페이지 구조

1. **히어로**: 제품명 + 핵심 메시지("면접에만 집중하세요 기록과 분석은 텔타 인터뷰 프로가 맡습니다") + 주요 기능 2가지 + CTA 버튼 2개
2. **문제 정의**: "흩어지던 인터뷰 내용을 변하지 않는 채용 데이터로"
3. **기능 상세** 3개 섹션: 실시간 스크립트, AI 어시스턴트, 역량 리포트
4. **비교표**: Interview Pro vs 기존 면접 방식 (5개 항목)
5. **요금제**: 구독형 4개 + Enterprise + 리포트 추가 요금
6. **사회적 증거**: 후보자 리포트 예시 2개 (UI 스크린샷 형식, 별도 고객 후기 섹션은 없음)
7. **FAQ** 4개
8. **최종 CTA**

## 카피 톤

- 전문적이면서 친근함. 문제-해결 구조.
- "면접에만 집중하세요" — 사용자의 행동에 초점을 두고, 나머지는 제품이 맡는다는 역할 분담 메시지.
- CTA는 "B2B 도입문의" + "무료로 시작하기" 2개를 히어로/본문 중간/최종 섹션에서 3회 반복. "매월 인터뷰 5건 무료"를 반복 노출.

## 인터뷰 흐름 시각화

- 실시간 진행 화면: 타이머(12:34/60:00), 일시정지/종료 버튼, 실시간 발언 기록, 메모 영역, AI 어시스턴트 패널(답변 요약, 추가 질문 추천)
- 데스크톱/태블릿/모바일 기기 이미지로 멀티디바이스 표현
- 결과 리포트 예시: 종합 점수(78/100), 인재상 태그, 역량 점수 시각화

## Acttub에 가져올 것 / 가져오면 안 되는 것

**참고할 만한 것**

- 히어로에서 "사용자는 X에만 집중, 나머지는 제품이" 구조의 한 문장 메시지 — Acttub이라면 "연기에만 집중하세요" 방향
- 인터뷰 진행 화면을 실제 UI 형태로 보여주는 방식 (채팅 화면, 질문 하나씩)
- 문제 정의 → 기능 상세 → FAQ → CTA의 섹션 흐름

**가져오면 안 되는 것 (가드레일 위반)**

- 종합 점수(78/100), 역량 점수 시각화 — Acttub은 점수·등급·평가를 사용자에게 노출하지 않는다
- 인재상 태그 같은 판정형 라벨 — 강점/약점 카드 금지에 해당
- "분석은 AI가 맡습니다"류 카피를 리포트에 적용하는 것 — Acttub 리포트는 AI의 결론이 아니라 배우 자신의 생각을 돌려주는 기록이다
